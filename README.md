# Тестовое задание: ML-разработчик

Анализ тональности русскоязычных текстов на датасете
[MonoHime/ru_sentiment_dataset](https://huggingface.co/datasets/MonoHime/ru_sentiment_dataset)
(≈211 тыс. текстов, 3 класса: neutral / positive / negative).

📓 **Ноутбук:** [`ml_test_mokhnev.ipynb`](ml_test_mokhnev.ipynb)
🔗 **Открыть в Colab** (интерактивные графики BERTopic GitHub не отображает): [ml_test_mokhnev.ipynb в Google Colab](https://colab.research.google.com/drive/1DvlkzUkYXsHhLLSZ6dpdiv4I7rNp_w0D?usp=sharing)

Среда: Google Colab, GPU NVIDIA Tesla T4.

## Что сделано

### Часть 1. EDA и тематическое моделирование
- **Анализ качества данных:** найдены дубликаты (8 788 в train), тексты с противоречивыми метками
  (3 090), утечка между train и test (1 617 текстов), мусорные тексты (`!`, `))`).
  Train очищен (осталось 176 697 текстов, 93%), test оставлен без изменений для честной оценки.
- **Распределение классов:** positive ≈ 48%, negative и neutral ≈ 26% → основная метрика macro-F1.
- **Тематическое моделирование — BERTopic** (эмбеддинги multilingual-MiniLM → UMAP → HDBSCAN → c-TF-IDF).
  Выбран вместо LDA/NMF, т.к. учитывает смысл текста, не требует лемматизации и сам определяет число тем.
  Найдено 13 тем, соответствующих источникам датасета: медицина, отели, рестораны, авто, новости,
  политика, комментарии из соцсетей.
- **Ключевая находка:** распределение тональности сильно зависит от темы (в медицинских отзывах
  почти нет neutral, в отелях — почти нет negative) — метка neutral размечена в источниках неоднородно.

### Часть 2. Классификатор тональности
- Разбиение: официальный validation → **test**; очищенный train → **train/val 90/10** со стратификацией.
- Метрика — **macro-F1**, функция потерь — **взвешенная кросс-энтропия** (учёт дисбаланса классов).

| Модель | macro-F1 (test) | accuracy | CPU, текстов/с | GPU, текстов/с | CPU, мс/текст |
|---|---|---|---|---|---|
| TF-IDF + LogReg (бейзлайн) | 0.753 | 0.756 | 4 287 | — | 3.9 |
| rubert-tiny2 (fine-tuning) | **0.784** | **0.788** | 45 | 669 | 12.7 |

- rubert-tiny2 лучше бейзлайна на 3.1 п.п. по всем классам; лучшая эпоха — 2-я из 3
  (на 3-й validation loss начал расти — признак переобучения).
- Самый сложный класс — neutral (основная путаница positive ↔ neutral), что согласуется с выводами EDA.
